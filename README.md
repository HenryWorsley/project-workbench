# 项目工作台 · Project Workbench

本地优先、可扩展的项目计划与执行工作台。它把甘特图、动态任务视图、日程、工作记录和报表导出放进一个清晰、克制的管理界面。

**当前版本：`v0.5.0-beta.1`**

> 这是公开测试版。仓库只包含虚构项目、虚构人员和模拟业务数据，不包含任何真实企业、客户或生产资料。

## 产品特色

- 首页直接展示可交互甘特图，支持按日、周、月查看
- 拖动任务条整体调整排期，拖动两端修改开始和结束日期
- 已完成、进行中、未开始、临期和逾期任务具有清晰的视觉区分
- 五套全局主题同步改变配色、任务条高度和动态节奏
- 支持项目、子项目、任务与子任务
- 动态任务碰撞场按照紧迫性和完成度组织任务
- 日程统一展示今日、本周、本月工作与关键里程碑
- 为任务追加进展、问题、优化与决策记录
- 导出 CSV 任务报表和 JSON 完整备份
- 无账号、无遥测、默认不连接业务服务器

## 快速开始

### 环境要求

- Windows、macOS 或 Linux
- Node.js `22.13` 或更高版本
- npm `10` 或更高版本

### 运行源码

```powershell
npm ci
npm run dev
```

默认访问 `http://localhost:3000`。

Windows 用户也可以双击 `启动项目工作台.bat`，脚本会使用 `http://localhost:3001`，避免与其他本地版本占用同一端口。

### 验证构建

```powershell
npm run typecheck
npm run build
```

## 数据与隐私

当前 Web 测试版把工作区数据保存在浏览器本机空间，数据不会自动上传。请注意：

- 清理浏览器网站数据、重装浏览器或更换浏览器配置可能导致本地数据丢失。
- 录入重要内容后，应立即在“系统设置”中下载 JSON 完整备份。
- 不要把唯一一份关键业务数据只保存在当前测试版中。
- 桌面稳定版发布前，计划迁移到带版本升级和自动备份能力的本地数据库。

## 版本规则

项目遵循语义化版本：

- `0.5.0-beta.1`：公开测试版，功能可体验但数据层与安装体验仍可能调整
- `0.x.y`：产品尚未承诺稳定兼容
- `1.0.0`：数据迁移、备份恢复、安装升级和核心交互达到稳定标准

版本历史见 [CHANGELOG.md](CHANGELOG.md)，每次发布前必须完成 [发布检查清单](docs/RELEASE_CHECKLIST.zh-CN.md)。
